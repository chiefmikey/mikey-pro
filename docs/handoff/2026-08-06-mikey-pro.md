The fix: `import-x/no-extraneous-dependencies` and the `jestJs`/`jestTs` overrides only recognized `*.test.{js,ts}` / `*.spec.{js,ts}` as test files. Any React/Vue test (`*.test.tsx`, `*.spec.jsx`), a file under `__tests__/`/`__mocks__/`, or a `*.config.*` file was NOT recognized — so importing `vitest`/`@testing-library/react` from one produced a false-positive extraneous-dependency lint error in every consumer project. Broadened both glob sets to cover the full extension matrix, narrow enough that a non-test `.tsx` importing a dev dependency still correctly errors.

The uncommitted diff claimed a regression test existed that didn't — wrote `tests/test-file-globs.test.js` (18 tests) to close that gap. Ran in isolation against real local source (confirmed via `node_modules` symlink, not a published copy): all 18 passed.
